# Multiple Horse Theory — Interactive Website

A self-contained satire/explainer site about the hypothesis that there may be more than one horse.

## Files

- `index.html` — full page markup
- `styles.css` — responsive visual system
- `script.js` — all interactions (no framework required)
- `assets/horse-mark.svg` — local logo/favicon

## Run it

You can double-click `index.html` and it will work locally in a modern browser.

For a local web server (recommended):

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
